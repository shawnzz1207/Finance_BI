# SPU 财务 BI 初稿

项目内置现有 2025、2026 经营数据的压缩快照，首次打开页面无需重复上传。
页面左侧仍提供原始经营报表导入入口；上传某一年度后，将直接覆盖该年度的内置数据，另一年度保持不变。
如果项目未包含内置快照，也可以使用环境变量 `FINANCE_BI_2025_PATH` 与 `FINANCE_BI_2026_PATH` 指定服务器默认原表。

```bash
python3 -m streamlit run FinanceBI.py
```

看板按 SPU 聚合，SKU/MSKU 只保留在导入映射层，不在页面、筛选和导出中显示。
毛利额和毛利率统一使用“毛利额-1”口径，库存相关成本以“库存折损”展示。

2026 年导入按前两行表头自动兼容 H1 的 78 列结构（BV 毛利润-1、BX 库存损失、BY 毛利润-2）和 1–8 月的 76 列结构（BV 毛利额-1源值、BW 库存损失、BX 毛利润-2）。H1 最后一列毛利率-2可省略。看板自行计算毛利率，未知表头结构会明确报错，不会仅按列数猜测。
